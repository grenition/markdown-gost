# ВВЕДЕНИЕ {.unnumbered}

Структурный заголовок должен быть без номера, по центру, прописными буквами
и с новой страницы.

# Первый раздел

Нумерованный заголовок первого уровня должен начинаться с номера без точки и
не переводиться в верхний регистр в строгом ГОСТ-пресете.

## Подраздел с обычным регистром

Подраздел не начинает новую страницу и сохраняет нумерацию второго уровня.

### Пункт третьего уровня

Заголовок третьего уровня нужен для визуального контроля каскада стилей.

# ЗАКЛЮЧЕНИЕ {.unnumbered}

Второй структурный заголовок также не должен увеличивать счётчик разделов.

# Второй раздел после структуры

Этот раздел должен получить номер 2, а не 3.
