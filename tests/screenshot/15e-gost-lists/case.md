Маркированный список должен использовать дефис как маркер.

- Первый пункт маркированного списка.
- Второй пункт маркированного списка с длинным текстом для проверки висячего
  отступа на переносе строки.

Буквенное перечисление пропускает запрещённые русские буквы.

1. первый элемент;

2. второй элемент;

3. третий элемент;

4. четвёртый элемент;

5. пятый элемент;

6. шестой элемент;

7. седьмой элемент;

8. восьмой элемент после пропуска запрещённой буквы;

9. девятый элемент.

Цифровое перечисление сохраняет закрывающую скобку из исходного markdown.

1) первый цифровой элемент;
2) второй цифровой элемент;
3) третий цифровой элемент.
