# ADR-0004: Пресеты конфигурации

- Статус: accepted (расширено 2026-09-17)
- Дата: 2026-09-17

## Контекст

Правила ГОСТ (поля, шрифты, нумерация, подписи) не хардкодятся в коде ядра:
они живут в YAML-пресетах (`src/markdown_gost/config/presets/`).
Изначально пресет выбирался только внутри YAML-конфига (`preset: <name>`),
отдельного флага CLI не было.

## Решение

`--config` в `convert` и `validate` принимает либо путь к YAML-файлу,
либо имя встроенного пресета:

```bash
markdown-gost convert input.md --config gost-7-32-2017
markdown-gost convert input.md --config my.yaml   # preset + overrides
```

Приоритет: существующий файл → имя пресета. Неизвестное значение — exit 1
со списком доступных пресетов. Источник имён — `available_presets()` из
`markdown_gost.config.presets`. Новый флаг для пресета не вводим:
переиспользуем существующий `--config` (короче, UX без лишних сущностей).

## Последствия

- Новый пресет = новый `*.yaml` в пакете; имя автоматически попадает
  в `--help` и в сообщение об ошибке.
- Поведение без `--config` не меняется (встроенный пресет по умолчанию).
- Файл, чьё имя совпало с именем пресета, трактуются как файл.
